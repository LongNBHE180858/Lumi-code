# Quy tắc làm việc với LUMI
- `AGENTS.md` ở gốc dẫn đến mục lục này; lưu nội dung quy tắc trong `Rules/`.
- Luôn đọc `Rules/project.md`, `Rules/conventions.md` và `Rules/workflow.md` trước khi làm việc.
- Chỉ đọc `Rules/topics/database.md` khi đụng đến schema, Liquibase, JDL, seed hoặc thao tác DB.
- Áp dụng quy tắc cho workspace `lumi-api` và `lumi-webapp`; kiểm tra repo chứa file trước khi dùng Git.
